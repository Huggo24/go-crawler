# Concurrent Web Crawler

Многопоточный веб-краулер на Go, реализованный с использованием архитектуры Worker Pool и примитивов синхронизации из стандартной библиотеки Go.

## Возможности

- **Параллельный обход страниц** — обработка нескольких URL одновременно с помощью горутин.
- **Worker Pool** — фиксированное количество воркеров для обработки задач.
- **Защита от дубликатов** — `sync.Map` для предотвращения повторной обработки URL.
- **Потокобезопасная очередь** — общая очередь задач с защитой через `sync.Mutex`.
- **Синхронизация воркеров** — `sync.Cond` для ожидания новых задач без активного опроса очереди.
- **Контроль завершения** — отслеживание количества незавершённых задач для корректного завершения работы краулера.
- **HTML-парсинг** — извлечение ссылок из страниц с помощью `golang.org/x/net/html`.
- **Ограничение времени ожидания** — HTTP timeout для предотвращения бесконечного ожидания ответа сервера.

## Используемые технологии

- Go
- `net/http` — выполнение HTTP-запросов.
- `net/url` — обработка и нормализация URL.
- `golang.org/x/net/html` — разбор HTML-документов.
- `sync.Map` — хранение обработанных URL.
- `sync.Mutex` — защита общей очереди.
- `sync.Cond` — синхронизация доступа к очереди.
- `sync.WaitGroup` — ожидание завершения горутин.

## Архитектура

Краулер использует общую очередь задач и пул воркеров.

Каждый воркер:
1. Получает URL из очереди.
2. Выполняет HTTP-запрос.
3. Разбирает полученный HTML-документ.
4. Извлекает ссылки со страницы.
5. Проверяет ссылки на соответствие условиям обхода и отсутствие дубликатов.
6. Добавляет новые URL в очередь.
7. Отмечает завершение текущей задачи.

Воркеры ожидают появления новых задач через `sync.Cond`. После обработки всех доступных задач краулер корректно завершает работу.

## Ограничения обхода

- Поддерживаются протоколы HTTP и HTTPS.
- Обход ограничен доменом исходного URL.
- Учитывается глубина обхода.
- Фрагменты URL игнорируются.
- Повторная обработка одного URL предотвращается.

## Запуск

Клонировать репозиторий:

```bash
git clone https://github.com/Huggo24/go-crawler.git
cd go-crawler
```

Установить зависимости:

```bash
go mod tidy
```

Запустить краулер:

```bash
go run . <url> <depth> <timeout(ms)> [workers]
```

### Аргументы командной строки

| Аргумент | Описание |
|---|---|
| `url` | Начальный URL для обхода |
| `depth` | Максимальная глубина обхода |
| `timeout(ms)` | Таймаут HTTP-запросов в миллисекундах |
| `workers` | Количество параллельных воркеров (необязательный аргумент, по умолчанию 10) |

Пример:

```bash
go run . https://example.com 2 5000 10
```

В данном примере краулер начинает обход с `https://example.com`, ограничивает глубину двумя уровнями, устанавливает таймаут HTTP-запросов в 5000 мс и использует 10 воркеров.
